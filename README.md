# Documented private-chef booking and repayment dispute

This repository contains a source-linked, English-language public record of a private-chef booking and repayment dispute in Guanacaste, Costa Rica.

The public page is intentionally limited to:

- the family's stated account;
- the business's stated account;
- links to the relevant public Reddit and Facebook discussions; and
- clear notes about what the available material does and does not establish.

Private chat exports, payment identifiers, contact details, and unverified media are excluded from the public site. The page does not use a password gate or accusatory graphics.
